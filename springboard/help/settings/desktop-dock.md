## The Dock {#dock}
The Desktop & Dock page holds the Dock settings.

## Minimise effect {#minimise}
A window that is minimised to the Dock animates with the effect you pick: Funnel Effect or Scale Effect.

## Hot corners {#hot-corners}
Moving the pointer into a screen corner runs an action. Each corner (Top Left, Top Right, Bottom Left and Bottom Right) can be set to None, Overview, Apps Grid, Show Desktop, Lock Screen or Search. Set a corner to None to stop it from acting when the pointer passes through.
