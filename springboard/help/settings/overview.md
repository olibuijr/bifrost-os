## Find a setting {#find}
Settings lists its pages in the sidebar. Type in the search field to find a page by name or by a word it covers.

## About this computer {#about}
The Overview page shows the BifrOSt version, the build and the computer's name, processor, memory and uptime. Use it to find the version to quote when you report a problem.

## Change the computer name {#name}
Open Sharing and edit the computer name. The name is the one other devices see on the network.
