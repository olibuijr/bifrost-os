# Changelog

## 0.1.4

- Rebuilt with the current renderer and SDK: Chinese, Japanese and Korean text draws whole, and a file opened with this app from Files or the Dock opens as a document.

## 0.1.3

- The toolbar is laid out in the pane's window position, so the SDK traffic-light inset leaves it where it is.

## 0.1.2

- Added the SDK and design compliance test harness.

## 0.1.1

- Exported the app icon at the required 180 x 180 pixel size.

## 0.1.0

- New app: Tips. Thirty-two short how-to cards about BifrOSt in five collections (Getting Started, Desktop, Windows,
  Files and Apps), read in a list and a card view.
- Search in the sidebar: every word must match a card's title, text, keywords or collection, ignoring case.
- New markers on cards you have not opened yet, a New collection in the sidebar, and Mark All Read in the toolbar.
- Left and Right move between cards in the list being read; Escape clears the search or returns to the list.
- The read state is saved in the app's data directory and kept between launches.
