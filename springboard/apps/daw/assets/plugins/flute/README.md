# Flute

Concert flute, non-vibrato sustain, 2 dynamics. Airy, pure, soaring highs. Range C4-C7 (best G4-C7). Melodies, countermelodies, pads doubled an octave up.

- Zones: 20 (2 velocity layer(s)), range MIDI 60-96
- Sustained, seamless loops (loopStart/loopEnd in seconds, crossfade baked in)
- Source: Versilian Studios VSCO-2 Community Edition (Sam Gossner / Versilian Studios), CC0 1.0. https://github.com/sgossner/VSCO-2-CE
- Built by `python3 tools/build-instruments-winds.py flute`
