# Clarinet

Bb clarinet, sustained, 2 dynamics. Warm woody low (chalumeau), clear bright top. Range D3-G6. Lyrical melodies, jazzy lines, soft inner harmonies.

- Zones: 22 (2 velocity layer(s)), range MIDI 50-91
- Sustained, seamless loops (loopStart/loopEnd in seconds, crossfade baked in)
- Source: Versilian Studios VSCO-2 Community Edition (Sam Gossner / Versilian Studios), CC0 1.0. https://github.com/sgossner/VSCO-2-CE
- Built by `python3 tools/build-instruments-winds.py clarinet`
