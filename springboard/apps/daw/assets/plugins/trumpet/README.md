# Trumpet

Solo trumpet, straight sustain, 2 dynamics. Bright, bold, penetrating. Range E3-D6 (best C4-C6). Fanfares, lead lines, brass stabs with short notes.

- Zones: 20 (2 velocity layer(s)), range MIDI 52-86
- Sustained, seamless loops (loopStart/loopEnd in seconds, crossfade baked in)
- Source: Versilian Studios VSCO-2 Community Edition (Sam Gossner / Versilian Studios), CC0 1.0. https://github.com/sgossner/VSCO-2-CE
- Built by `python3 tools/build-instruments-winds.py trumpet`
