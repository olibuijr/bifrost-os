# Contrabass

Solo double bass, sustained arco with vibrato, 2 velocity layers, looped. MIDI ~28-60. Deep orchestral bass, pedal tones, low drones.

- Source: https://github.com/sgossner/VSCO-2-CE/tree/master/Strings/Solo%20Contrabass/SusVib
- License: CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/)
- Attribution: VS Chamber Orchestra: Community Edition (VSCO-2 CE) by Versilian Studios (Sam Gossner, Simon Dalzell; sample cutting by Elan Hickler/Soundemote). CC0 1.0.

Processed by tools/build-instruments.py: onset-trimmed, normalized, cut to <=5 s, sustain loop with baked equal-power crossfade, Ogg Vorbis q4, 44.1 kHz.
`tune` (if present) = cents to add at playback to correct the recording's pitch.
