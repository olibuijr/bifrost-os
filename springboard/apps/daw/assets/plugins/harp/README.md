# Harp

Concert harp, plucked mf, natural ringing decay (no sustain). Range C1-G7. Arpeggios, glissandi-style runs, sparkling ostinatos, gentle chords.

- Zones: 21 (1 velocity layer(s)), range MIDI 24-103
- Plucked, natural decay, no loop
- Source: Versilian Studios VSCO-2 Community Edition (Sam Gossner / Versilian Studios), CC0 1.0. https://github.com/sgossner/VSCO-2-CE
- Built by `python3 tools/build-instruments-winds.py harp`
