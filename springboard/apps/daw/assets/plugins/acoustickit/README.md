# Acoustic Kit

Real acoustic jazz/studio drum kit (multi-mic, 2 velocity layers). Jazz, soul, neo-soul, live hip-hop, funk, rock. Ride 51 swing patterns, hats 42/44/46, snare 38 (40 rimshot, 37 cross-stick), toms 45/47/50, crash 49. Use velocity for ghost notes.
