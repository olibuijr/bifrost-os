# 808 Distorted

Saturated 808 bass with harmonics that stay audible on phones/laptops (~4 s). Trap/drill/hard hip-hop: play the bassline in MIDI 24-48, long notes on the kick, glide 0.05-0.15 with overlapping notes for slides. Mono.
