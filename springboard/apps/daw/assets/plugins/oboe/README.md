# Oboe

Oboe, sustained non-vibrato, 2 dynamics. Nasal, plaintive, cutting. Range Bb3-G6. Solo melodies, pastoral themes, doubling strings.

- Zones: 18 (2 velocity layer(s)), range MIDI 58-91
- Sustained, seamless loops (loopStart/loopEnd in seconds, crossfade baked in)
- Source: Versilian Studios VSCO-2 Community Edition (Sam Gossner / Versilian Studios), CC0 1.0. https://github.com/sgossner/VSCO-2-CE
- Built by `python3 tools/build-instruments-winds.py oboe`
