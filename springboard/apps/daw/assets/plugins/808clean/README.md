# 808 Clean

Deep, clean TR-808 style sub bass (sine + pitch drop, ~4.5 s decay). Hip-hop/trap/R&B bass: follow the kick & root notes in MIDI 24-48 (C1-C3); note length = how long it booms. glide>0 + overlapping notes = 808 slide. Mono (new note cuts the last).
