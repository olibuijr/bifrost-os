# Trap Kit

Trap/drill kit (synthesized 808 voices): long 808 kick, tight clap/snare, crisp hats for rolls. 130-150 BPM (half-time feel): snare/clap on 3, hats in 8ths with 16th/32nd/triplet rolls (short notes, vary velocity), open hat 46 on offbeats, kick 36 with the 808 bass. 42 chokes 46.
