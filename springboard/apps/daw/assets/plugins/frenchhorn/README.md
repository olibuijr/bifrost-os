# French Horn

Solo French horn, sustained, 2 dynamics. Round, noble, mellow; brassy when loud. Range A1-F5 (best C3-C5). Heroic themes, warm chord pads, film swells.

- Zones: 22 (2 velocity layer(s)), range MIDI 33-77
- Sustained, seamless loops (loopStart/loopEnd in seconds, crossfade baked in)
- Source: Versilian Studios VSCO-2 Community Edition (Sam Gossner / Versilian Studios), CC0 1.0. https://github.com/sgossner/VSCO-2-CE
- Built by `python3 tools/build-instruments-winds.py frenchhorn`
