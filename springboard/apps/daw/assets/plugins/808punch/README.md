# 808 Punch

Short punchy 808 (~1 s, snappy pitch drop + click), doubles as a tuned kick. Boom-bap/trap/G-funk: 8th/16th-note basslines in MIDI 24-48 locked to the kick; tune notes to the key root. Mono; glide for slides.
