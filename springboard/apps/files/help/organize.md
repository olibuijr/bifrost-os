## Create a folder {#new-folder}
Choose New Folder. Type the name and press Return. If the name is taken the folder gets a new name, and Undo removes it again.

## Rename an item {#rename}
Choose Rename, or click the name of a selected item, and type the new name. Copy Name copies the name to the clipboard.

## Duplicate, copy and move {#copy-move}
Duplicate makes a copy of the selected items in the same folder. Copy and Paste copy items into another folder. Move moves them. If a file with the same name is already there, choose Keep Both to keep the two, or Replace to overwrite it.

## Move to the Trash {#trash}
Move to Trash puts the selected items in the Trash. Undo Trash brings them back straight away. Open the Trash to put an item back to where it came from with Put Back.

## Empty the Trash {#empty-trash}
Empty Trash deletes everything in the Trash for good, and cannot be undone. Cancel stops the job before it starts deleting.

## Tags {#tags}
Tags labels an item with a colour so you can find it later. Choose Tags in the sidebar to show every item with that tag.
