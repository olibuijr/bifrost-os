## Find text {#find}
Choose Find in the Edit menu to search the document. Find Next and Find Previous move between the matches. Jump to Selection moves the view to the selected text.

## Check spelling {#spelling}
Check Spelling While Typing underlines misspelled words as you type. Check Document Now checks the whole document at once. Click an underlined word to see its suggestions, then choose Correct Spelling or Ignore Spelling. Learn Spelling adds a word to the dictionary so it is no longer marked.

## Print {#print}
Print sends the document to the printer. Page Setup chooses the paper size and the orientation, Portrait or Landscape. Print Header and Footer adds the document's name and the page numbers ("Page n of m") to each printed page. If no printer is set up, Print shows a message instead.

## Export as PDF {#pdf}
Export as PDF saves the document as a PDF file, with the same pages as the print. A message confirms the export, and reports the reason when it fails.

## Document properties {#properties}
Document Properties sets the title, author, keywords and copyright that are stored with the document.
