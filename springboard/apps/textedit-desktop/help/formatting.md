## Bold, italic and underline {#style}
Select the text and choose Bold, Italic or Underline in the Format menu. Choose the same item again to remove the style.

## Fonts and size {#font}
Show Fonts opens the font panel. Pick a family and a size there, or choose Bigger and Smaller to step the size of the selection. Default Font returns the selection to the document's font.

## Alignment {#align}
Align Left, Center, Align Right and Justify set how the paragraphs line up. Alignment applies to every paragraph the selection touches.

## Colour and highlight {#colour}
Show Colors opens the colour panel. The colour applies to the selected text. Highlight marks the selected text with a background colour.

## Capitalisation {#case}
Make Upper Case, Make Lower Case and Capitalize change the letters of the selection.

## Bullets {#bullets}
Bullets starts a bulleted list from the current paragraph. Press Return at the end of an item to add the next one.

## Links {#link}
Select text and choose Link to add a web address to it. Open Link opens the link in the browser. Remove the link by clearing its address.
