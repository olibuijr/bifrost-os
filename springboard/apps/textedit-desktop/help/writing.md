## Start a document {#new}
Choose New Document in the File menu. Each document opens in its own window, and New Window Containing Selection opens the selected text in a new window.

## Rich text and plain text {#rich-plain}
A document is either Rich Text, which keeps fonts, sizes and colours, or Plain Text, which keeps only the characters. Choose Make Plain Text or Make Rich Text in the Format menu to change it. Make Plain Text asks first, then removes the formatting and attachments and shows the text in a fixed-width font.

## Save and open {#save}
Save writes the document to its file. Open shows the files you can open in TextEdit. Plain text files keep their encoding; choose Plain Text Encoding in the Format menu to pick another one.

## Select text {#select}
Click to place the caret and drag to select. Double-click selects a word and triple-click a paragraph; drag after a double or triple click to select by whole words or paragraphs. With the keyboard, Shift with the arrow keys, Home or End extends the selection, Alt with an arrow moves by word, and Cmd with Left or Right moves to the start or end of the line.

## The title and the format bar {#bar}
The window's title is the document's name, with Edited after it while there are unsaved changes. Below it the format bar holds the controls for the selected text, or for the text you type next when nothing is selected: Bold, Italic, Underline and Strikethrough, the text colour, the font, its style and size, the alignment, lists and the line spacing. When the window is too narrow for all of them, the rest are in the button at the end of the bar.

## Wrap lines {#wrap}
Wrap to Window fits the lines to the width of the window. Wrap to Page fits them to the paper, so the page layout shows before you print.

## Show the ruler {#ruler}
Show Ruler and Hide Ruler show or hide the ruler above the text. The ruler holds the tab stops and indents of the paragraph.
