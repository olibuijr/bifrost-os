## Text limitations

Default-ignorable characters are removed from visible glyph placement and
measurement. Joiners remain in the shaping input where supported. A soft hyphen
appears when a line ends at it; the line-fitting step does not yet reserve the
visible hyphen's width, so that break can exceed the width by one hyphen.
This is not a claim of complete script shaping or reference text-layout parity.
