# Mail computer-use E2E, 2026-10-23

Tested Mail 0.17.1 on Midget, initially system 0.10.22. Input uses real
uinput keyboard/pointer events and compositor screenshots, with a persistent
pointer device for hover. No message was sent. Private screenshots and replay
scripts remain in `out/mail-e2e-2026-10-23/`.

## Observed working

- Message selection and Up/Down navigation update the header and fetched body.
- Context menus fit on screen and Escape dismisses them; menu-bar menus open.
- Double click opens a separate message viewer; Cmd+W closes it.
- Find opens with Cmd+F, narrows the list, and clearing the query restores it.
- Cmd+N opens a compose window; Tab traverses To, Cc, Subject and Message.
- Physical Enter inserts a second body line. Attach opens the file picker.
- Closing a modified compose asks Don't Save / Cancel / Save; Don't Save closes it.
- On a fresh floating main window, Drafts navigation and the compose toolbar work.
- Shift-click selected exactly five temporary test drafts; moving those to Trash
  removed them from Drafts while retaining all pre-existing drafts.

## Findings under investigation

After testing extra viewers/composes with the main window maximized, sidebar
clicks selected inbox rows instead and the compose toolbar stopped responding.
Quitting and reopening into a floating main window restored those controls. This
is a reproducible observation of stale geometry, not yet a confirmed root cause.
MailApp::configure updates the stored main size while handling configurations;
extra-window dispatch needs investigation before attributing the defect.

Wheel scrolling did not move the list or reader during that earlier sequence.
A fresh floating Inbox does scroll with the same uinput wheel command; the earlier
problem is therefore state-dependent rather than a universally missing handler.

The first temporary compose produced five Drafts rows with the same test subject.
These were visible after reopening Drafts. The five rows were selected by their
unique test subject and moved to Trash; no pre-existing draft was selected.
The second multiline/attachment compose was explicitly discarded.

Two originally unread inbox messages were opened by misdirected clicks; their
unread flags were restored through Message > Mark as Unread before quitting.
No existing message was archived, trashed or sent.

## Scope and limits

Green-button full-screen entry and Cmd+Ctrl+F exit work, restoring the floating
window. A toolbar click near the full-screen top edge revealed the menu bar and
Notification Center, so that click is not evidence of a Mail toolbar defect.
Light appearance was inspected on Midget for the main and compose windows
(captures 53–54); both use readable light surfaces, text and controls. Dark was
restored afterward. Send, delivery, attachment upload and
destructive actions on existing messages are outside this test.
