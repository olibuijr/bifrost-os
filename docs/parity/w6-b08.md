# Parity wave 6, batch b08

Closes five of the ten `gap` rows in six framework files (user-notifications-ui, visionkit, webkit, widgetkit,
app-intents-testing, synchronization). All code is pure Rust, std only, with no `unsafe`. No build or test was run in
this round: the lead builds once at the end.

## What was built

| Module | Mirrors (official names) | What it does |
|---|---|---|
| `springboard/sdk/src/synchronization.rs` (extended) | `WordPair` (`init(first:second:)`, `first`, `second`) | `WordPair` value type and `AtomicWordPair`, a pair stored behind one lock: `load`, `store`, `exchange`, `compare_exchange`. Lock based, not a hardware double-word atomic. |
| `springboard/ui/src/value_query.rs` | `ResolvedValueQueryResult` (`items`) | `ValueItem` (id, title, named properties) and `ValueQueryResult`: query-order items, lookup by id, filter by property value. Rejects empty and duplicate ids. |
| `springboard/ui/src/onscreen_entity.rs` | `ViewAnnotation` (`entity`, `isSelected`) | `OnscreenContext` maps view numbers to an `EntityRef` with selection and visibility; `view_annotations()` returns only visible views in view-number order. |
| `springboard/ui/src/dom_snapshot.rs` | `WKDOMNodeSnapshot` (DOM node snapshot) | `DomSnapshot`, a validated immutable tree built from flat `NodeRecord`s: root, children, document order, attributes, text content, attribute search. Rejects duplicate ids, two roots, unknown parents, cycles and missing roots. |
| `springboard/ui/src/context_element.rs` | `WKContextMenuElementInfo` (`linkURL`) and the context menu | `ContextElement::from_chain` reads the link, image and editable state from an engine hit chain; `menu()` picks Editable, Link, Image or Page. Only http, https and mailto links and http and https images are accepted. |

Module registrations: four `pub mod` lines in `springboard/ui/src/lib.rs`. `WordPair` is in the existing
`synchronization` module, which is already registered in `springboard/sdk/src/lib.rs`.

Engine wiring is not part of this round. The DOM snapshot and the context element take records the web engine would
report; no code in `springboard/sdk/src/webview*.rs` calls them yet, so their matrix status is `partial`.

## Rows skipped (remain `gap`)

| Framework slug | Feature | Reason |
|---|---|---|
| webkit | WebDriver and automated testing | Needs a WebDriver server that drives the page engine over a network protocol. Network services are out of scope for this batch. |
| user-notifications-ui | Notification content app extension (custom notification view) | An app-supplied view for a delivered notification needs a separate extension process and shell rendering of that view. No such process exists. |
| visionkit | Subject lifting and background removal | Needs an image segmentation model. A pure-Rust threshold would not match the official behaviour, so it is not claimed. |
| visionkit | Visual Look Up | Needs a lookup service and reference data. Neither is available offline in pure Rust. |
| widgetkit | Location and network access in widgets | No widget process exists, so there is no per-widget location or network grant to model. |
