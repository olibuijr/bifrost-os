# Parity wave 6, batch b15

Branch `parity/w6-b15` (on top of main, release 0.5.36). Closes one gap row across five framework files.
Nothing built or run (no cargo); the lead builds once at the end.

## What was built

- `springboard/ui/src/layout_protocol.rs` (new, registered in `springboard/ui/src/lib.rs` as `pub mod layout_protocol;`).
  - `trait Layout`: `size_that_fits(proposal, subviews)` and `place_subviews(bounds, proposal, subviews)`, with
    subview ideal sizes as `(width, height)` and `f32::INFINITY` for an unbounded proposal.
  - `FlowLayout { spacing_x, spacing_y }`: a wrapping row layout. Subviews go left to right and wrap when the next
    one passes the proposed width. The first subview on a row never wraps, even when wider than the proposal.
  - Six behaviour tests with values worked out by hand from the wrap rule.
- Mirrors the official Layout protocol: `sizeThatFits(proposal:subviews:cache:)` and
  `placeSubviews(in:proposal:subviews:cache:)`. The cache, alignment-guide, spacing and layout-property methods
  are not mirrored in this round.

## Official API names mirrored

- `Layout` (https://developer.apple.com/documentation/swiftui/layout)
- `Layout.sizeThatFits(proposal:subviews:cache:)`
- `Layout.placeSubviews(in:proposal:subviews:cache:)`
