# Parity wave 6, batch b14

Branch `parity/w6-b14`, on top of release 0.5.36. The lead builds once at the end; this round ran no builds or tests.

## What was built

- `springboard/ui/src/textview.rs` (`bifrost_ui::textview`): a multi-line text view model. Greedy word wrap into byte
  ranges (`layout`, `line_of`, `x_of`, `byte_at`), and a `TextView` that owns a `text::TextEditor`, so typing, undo and key
  bindings are the single-line field's. It also covers caret point, hit testing, vertical movement with a goal column,
  horizontal movement, scroll with clamping, scroll-to-caret, the visible line range, and selection highlight pieces per
  line. It is a pure model with no drawing and no SDK wiring yet. Eight host tests are written; they have not been run.
- `springboard/ui/src/lib.rs`: one `pub mod textview;` line.

## Official API mirrored

- `NSTextView` (AppKit, Text): the front-end text view that draws wrapped text and handles selection and editing
  (https://developer.apple.com/documentation/appkit/nstextview). The model mirrors the view's caret, selection, hit
  test and scroll behaviour. It does not mirror the text container, layout manager or delegate protocols.
