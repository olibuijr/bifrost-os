# Parity wave 6, batch b04: location authorization, location errors, flight numbers

Batch b04 covers the gap rows of Core Location, Core ML, Core Motion, Core Spotlight, Core Text and DataDetection.
Three rows can be built honestly in pure Rust with no hardware, network service or trained model. Five other rows
are skipped, each with a reason below. Status for the closed rows is `partial`: the model and the classification are
built, but no shell service produces the values or shows the prompt.

## What was built

### `springboard/ui/src/location_auth.rs` (new, `bifrost_ui::location_auth`)

- `AuthorizationStatus` (not determined, restricted, denied, authorized always, authorized when in use), with
  `is_authorized`, `may_start(in_foreground)` and `request_outcome`. Mirrors the official authorization status values.
- `AccuracyAuthorization` (full accuracy, reduced accuracy), with `is_full`. Mirrors the official accuracy values.
- `RequestOutcome` (prompt, already granted, refused): what a request does in each status.
- `UsageDescriptions` and `Level`: the text shown to the user for each level, `for_level` returning the trimmed text
  or `UsageError::Missing` when it is blank. The official usage keys are not used here, because the owner rule keeps
  platform identifiers out of code. The text is stored by level, not under those keys.
- `LocationError` (19 cases, names from the official error reference), `ERRORS`, `code`, `from_code` and
  `DOMAIN = "bifrost.location"`. The numeric codes are BifrOSt's own, numbered in declaration order. The official
  numeric values were not fetched, so they are not mirrored.
- `needs_user_action` and `is_transient`: the classification rules are this module's own.

Pure model: no prompt, no service, no error is raised by this module.

### `springboard/ui/src/detect.rs` (changed)

- `Kind::Flight` added to the detector, with priority after money and before phone numbers.
- `flights`: a two-character airline code in capitals (a capital, then a capital or a digit), an optional single space,
  then one to four digits that end at a word boundary, for example `FI 552` or `BA117`. Lower-case letters do not
  count. This is a heuristic: two capitals before digits can still be an ordinary word.
- `flight_parts`: splits a flight match into its airline code and number, `("FI", "552")`.

`lib.rs` gets one line: `pub mod location_auth;`.

## Official API names mirrored

- Core Location: `CLAuthorizationStatus` (cases `notDetermined`, `restricted`, `denied`, `authorizedAlways`,
  `authorizedWhenInUse`), `CLAccuracyAuthorization` (`fullAccuracy`, `reducedAccuracy`), `CLError` (19 cases).
  Official pages: https://developer.apple.com/documentation/corelocation/clauthorizationstatus ,
  https://developer.apple.com/documentation/corelocation/claccuracyauthorization ,
  https://developer.apple.com/documentation/corelocation/clerror-swift.struct
- DataDetection: `DDMatchFlightNumber` (fields `airline`, `flightNumber`). Official page:
  https://developer.apple.com/documentation/datadetection/ddmatchflightnumber

## Rows skipped

| Framework slug | Feature | Reason |
|---|---|---|
| core-location | Location manager and live updates | Needs a device position source (GPS or positioning hardware). Nothing on the PC supplies a position, and no hardware is accessed. |
| core-ml | Model encryption | Needs a cipher and a key format. Pure std Rust has no cipher, and no crate is allowed. The official encryption pages were not read for the format. |
| core-ml | Domain frameworks built on Core ML | Vision, speech, natural language and sound analysis need trained models. None are in the repo, and no network service is allowed. |
| core-motion | Raw accelerometer events | Needs the accelerometer sensor. No sensor reader exists and no hardware is accessed. |
| core-motion | Raw gyroscope events | Needs the gyroscope sensor. No sensor reader exists and no hardware is accessed. |
| core-spotlight | Foundation models search tool | Needs an on-device language model to act as the search tool. None exists in the repo. |
| core-text | Ruby annotations | The official DocC page for the ruby annotation type lists no members, so no API surface to mirror could be fetched. The row is left as a gap rather than invented. |
