# Parity wave 6, batch b06: natural language, notification center, Quick Look, Safari services, social

Branch `parity/w6-b06`, started from `main` at release 0.5.36. Rows are closed as `partial`: each is a pure model with
host unit tests. None of them is wired into an app or the shell yet, and none is tested on Midget, so no row is
`parity`.

Only the gap rows of these six files were in scope. Five rows are closed as partial, and five are skipped with
reasons. Existing modules were extended where they already covered part of a row (`preview.rs`, `compose.rs`,
`social.rs`, `peek.rs`); no module was duplicated under another name.

## What was built

| Area | Module | What it does |
|---|---|---|
| Text classifier | `springboard/ui/src/text_classifier.rs` (new) | A bag-of-words text classifier built on the existing `ml_model::Model` (one dense layer and a softmax). Predicts a label, labels for tokens, and the top hypotheses with probabilities. Text with no vocabulary word has no label. |
| Search view | `springboard/ui/src/widget_search.rs` (new) | Search results shown by a widget: the description line, the placeholder for an empty list, the results and the title each one shows. |
| Embedded preview | `springboard/sdk/src/peek.rs` (`PreviewView`, existing) | The lead dropped this wave's duplicate `ui/src/preview_view.rs` at merge: the SDK already had the same model. |
| Data preview provider | `springboard/ui/src/preview.rs` (extended) | `PreviewProvider` trait (in process) and `Registry::preview`, which runs the provider the registry picks for a file's type. It uses the existing `Reply` and `Registry` models. |
| Compose sheet | `springboard/ui/src/compose.rs` (extended) | `ComposeSheet`: a draft that locks once presented, and a result recorded when the user finishes. Adds `ComposeError::Locked` and `SheetState`. Re-exported from `springboard/sdk/src/social.rs`. |

`lib.rs` gains two `pub mod` lines (`text_classifier`, `widget_search`). No other crate's
`lib.rs` changed.

## Official API names mirrored

Reference facts come from the official DocC JSON (`tools/parity/docc.py`) and the rendered pages (REA).

- Natural Language: `NLModel` (`predictedLabel(for:)`, `predictedLabels(forTokens:)`,
  `predictedLabelHypotheses(for:maximumCount:)`). https://developer.apple.com/documentation/naturallanguage/nlmodel
- Quick Look UI: `QLPreviewView` (`init(frame:style:)`, `previewItem`, `refreshPreviewItem()`, `displayState`,
  `autostarts`, `shouldCloseWithWindow`, `close()`) and `QLPreviewViewStyle` (`normal`, `compact`).
  https://developer.apple.com/documentation/quicklookui/qlpreviewview
- Quick Look UI: `QLPreviewProvider` (the data-based preview provider).
  https://developer.apple.com/documentation/quicklookui/qlpreviewprovider
- Quick Look: `QLPreviewReply` (already modelled in `preview.rs`; used here as the provider's return value).
  https://developer.apple.com/documentation/quicklook/qlpreviewreply
- Notification Center: `NCWidgetSearchViewController` (`searchDescription`, `searchResultsPlaceholderString`,
  `searchResultKeyPath`, `searchResults`). The page marks it deprecated in favour of WidgetKit.
  https://developer.apple.com/documentation/notificationcenter/ncwidgetsearchviewcontroller
- Social: `SLComposeViewController` (`setInitialText(_:)`, `add(_:)` for image and URL, `removeAllImages()`,
  `removeAllURLs()`, `completionHandler`, `SLComposeViewControllerResult`).
  https://developer.apple.com/documentation/social/slcomposeviewcontroller

Differences from the reference APIs:
- The text classifier is built in code from its weights. The reference SDK's trained-model file formats are not
  read, and the word tagger is not modelled.
- Setters on the compose sheet return `Result<(), ComposeError>`, not a Boolean. `Locked` is the reason for the
  framework's `false`.
- The search view takes an accessor function where the reference API takes a key path (a string property name).
- The preview provider runs in the same process. No extension bundle is loaded.
- The preview view's model does not render. The item is a name or path that the app loads; drawing it is up to the
  shell.

## Rows skipped

| Framework slug | Feature | Reason |
|---|---|---|
| natural-language | Contextual embedding (NLContextualEmbedding) | Needs per-script model assets that the reference SDK downloads. This batch has no asset loader and no network service, and the model itself is not pure Rust. |
| quick-look | PDF multi-page preview context | The reference API hands a PDF drawing context to a callback. The PDF renderer is outside this batch (`springboard/ui/src/pdfpage.rs` and the PDF app), so there is no honest pure model of the context yet. |
| safari-services | Safari web extensions and Safari app extensions | Needs an extension host and page and tab proxies inside the browser engine process. That is not pure Rust in this batch, and the browser has no extension API yet. |
| safari-services | Authentication sessions (shared Safari login) | Sharing a login across apps needs the browser's cookie store. `springboard/ui/src/webauth_session.rs` already models the sign-in session flow, but it does not share cookies, so the row stays a gap. |
| social | Social account credentials | No social-network account store, no token signing and no network. Secrets are not built here. |

## Verification

- No build was run, as the task requires. Every file was checked by reading: type and borrow shapes, the
  `ModelError` and `Result` conversions, and the imports (`FeatureProvider` for `value`, `Model` derives `Clone` and
  `Debug`).
- `python3 -I tools/check-names.py` exits 0 with no hits (owner name rule). The new code uses the `Native` prefix
  convention from `language.rs`, and Apple class names appear only in this report.
- Tests added, each worked out by hand from the rule it checks:
  - `text_classifier.rs` (9 tests): word splitting; the top label; the softmax value 1/(1+e^-4) = 0.98201 for
    counts (hi 2, bye 1); unknown words give no label; hypothesis limits; the tie rule; token labels; construction
    errors (`LayerSize`, `BadWord`, `Duplicate`, `Empty`); vocabulary and label order.
  - `widget_search.rs` (5 tests): placeholder shown only when empty; order of rows; replacement and clear; no
    placeholder when none is set; trimming of description and placeholder.
  - `preview_view.rs` (6 tests): empty defaults; autostart goes to Loading then Ready; no autostart waits for refresh;
    blank item empties the view; close releases the item; the window closes the view only when asked.
  - `preview.rs` (1 test): a data preview comes from the registry's provider; unknown types and missing providers
    give `None`; a failing provider reports its error.
  - `compose.rs` (5 tests): the sheet locks once presented; finish reports `Done` and closes; blank text or a
    dropped post reports `Cancelled`; draft limits apply inside the sheet; the `Locked` message.
- Not tested on the host or Midget yet. The lead's integration build should run these tests.
