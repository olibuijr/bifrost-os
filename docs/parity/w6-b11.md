# Parity wave 6, batch b11

Closes four of the gap rows in the six frameworks of this batch, as pure Rust models with host unit tests.
Nothing is wired into apps, the shell or the audio daemon, and nothing is tested on the VM or Midget yet.
No build was run in this batch; the lead builds once at the end.

## What was built

| Module | Mirrors (official API) | What it does |
|---|---|---|
| `springboard/ui/src/particle_system3d.rs` (`ParticleSystem`, `Particle3`) | SceneKit `SCNParticleSystem`: `birthRate`, `particleLifeSpan` (+ variation), `particleVelocity` (+ variation), `emittingDirection`, `gravity` acceleration, `loops`-free start/stop | Emitter at a point with a seeded `emitter::Rng`; whole particles spawned from a fractional carry; semi-implicit Euler integration; removal at the life span; population cap. |
| `springboard/ui/src/scene_audio.rs` (`AudioPlayer`, `Gains`, `distance_gain`) | SceneKit `SCNAudioPlayer` (positional playback attached to a point) | Inverse-distance attenuation, box occlusion from `sound_space::occlusion_gain`, equal-power pan from `sound_space::pan_gains`; a non-positional mode; play and stop. |
| `springboard/ui/src/coordinate_space3d.rs` (`SpaceTree`, `SpaceId`) | Spatial `CoordinateSpace3D`: `convert(value:from:)`, `convert(value:to:)`, `transform(from:)`, `worldReference` | Tree of spaces with a world reference (`SpaceTree::WORLD`), `Matrix4` transform per space, point conversion between any two spaces through the world. Singular transforms and unknown parents are refused. |
| `springboard/core/src/smf.rs` (`Smf`, `Event`, `Message`, `Playback`) | AVFAudio `AVMIDIPlayer`: `init(contentsOf:)`, `play`, `stop`, `isPlaying`, `rate`, `currentPosition`, `duration` | Standard MIDI File parser (formats 0 to 2, running status, tempo map, end-of-track), time-sorted channel messages in seconds, and a `Playback` walk with rate and seek. No sound bank, so no audio is produced. |

Reused, not duplicated: `emitter::Rng`, `linalg::{Vector3, Matrix4}`, `sound_space::{Listener, Occluder, Vec3, pan_gains, occlusion_gain}`.

## Matrix rows closed (new status `partial`)

| Framework slug | Feature (as in `docs/parity-matrix/data/<slug>.json`) | New status | BifrOSt path |
|---|---|---|---|
| scenekit | Particle systems | partial | `springboard/ui/src/particle_system3d.rs` |
| scenekit | Positional audio | partial | `springboard/ui/src/scene_audio.rs` |
| spatial | Coordinate spaces | partial | `springboard/ui/src/coordinate_space3d.rs` |
| avfaudio | MIDI playback (AVMIDIPlayer) | partial | `springboard/core/src/smf.rs` |

Gaps still open on these rows: the particle system has no emission duration, idle periods, spreading cone, size, colour, texture or
property controllers; positional audio has no sample playback, Doppler or source-to-engine hook; coordinate spaces have no view transforms
and no projective transforms; MIDI has no soundbank, so nothing is heard.

## Rows skipped

| Framework slug | Feature (as in the matrix) | Reason |
|---|---|---|
| replaykit | Live broadcast controller and handlers | Needs a broadcast extension point and streaming of app frames to a network service. Network services are out of scope for this batch. |
| replaykit | Broadcast picker UI | There is no broadcast service to choose from; the share picker only lists sharing targets. |
| scenekit | Views for 3D content | Needs a 3D GPU render path. The presenter in `springboard/src/gpu/wl.rs` draws 2D surfaces only, and no hardware access is allowed here. |
| scenekit | Custom shaders and render passes | Needs an app-facing shader or render-technique pipeline on the GPU. Not buildable in pure Rust without hardware. |
| spritekit | Renderer hand-off and custom Metal pipeline | The presenter is internal. Handing a scene to an app's own render pipeline needs the GPU path, which is out of scope. |
| audio-unit | Implementing AU v3 plug-in extensions | Needs an extension host that loads third-party audio processors in separate processes. No such host exists and it is not pure Rust. |

## Checks

- `python3 tools/check-names.py`: exit 0, no hits.
- Each new module has a `#[cfg(test)] mod tests` with five or more behaviour tests whose values were worked out by hand:
  - `scene_audio`: 1/3 gain at 3 m with reference 1 and rolloff 1; right-ear only at 2 m; 0.25 * sqrt(1/2) through a 0.5 wall; stopped and volume; non-positional pan.
  - `particle_system3d`: 2 then 5 particles at 10 per second over two 0.25 s steps; gravity path (2, -2.5, 0) and removal at 1.0 s; emitter position; cap at 2; life-span range 1.5 to 2.5 and seed repeatability; zero direction falls back to up.
  - `coordinate_space3d`: translation, grandchild scale plus offset giving (3, 2, 2), sibling conversion giving (1, -5, 0), identity self-transform, rejection of unknown parents and singular scale.
  - `smf`: 0.5 s note-off at 480 ticks, 1.5 s with a tempo change at tick 96, running status giving 10/960 s, velocity 0 as note-off, pitch bend 8192, error cases, playback walk, rate and seek.
