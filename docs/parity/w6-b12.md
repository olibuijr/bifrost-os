Status: partial build. One module, `springboard/ui/src/media_trim.rs`, closes one gap row in AVKit.

## What was built

- `bifrost_ui::media_trim`: a pure trimming session for a player view. It mirrors the trim mode of the
  player view (can begin, begin, set in-point and out-point, finish with OK or Cancel). In-point and out-point
  are clamped to the media and keep a minimum clip length. Drawing the trim bar and writing the trimmed
  file are left to the caller.
- Six tests with hand-worked values (begin rules, minimum length, clamping of both edges, OK versus Cancel,
  edits outside trimming, NaN and infinite inputs).

## Official API names mirrored

- AVKit: `AVPlayerViewTrimResult` (`okButton`, `cancelButton`), `canBeginTrimming`, `beginTrimming(completionHandler:)`.
  Source: https://developer.apple.com/documentation/avkit (Trimming media section), read via `tools/parity/docc.py avkit/avplayerviewtrimresult`.
