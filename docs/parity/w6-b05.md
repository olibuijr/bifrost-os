# Parity wave 6, batch b05

Gap rows of six frameworks: ExtensionFoundation, File Provider, JavaScriptCore, MailKit, MapKit and Matter.
Of the ten gap rows, three are closed with pure Rust models (status `partial`), and seven are skipped with a reason. Nothing here
runs on the VM or on Midget yet, so no row is `parity`.

## What was built

- **Map view state** (`springboard/ui/src/mapview.rs`, extended). `MapView` holds a `MapCamera`, a `MapType`
  (standard, hybrid, imagery), a `MapInteraction` set of four switches (zoom, scroll, pitch, rotate), a pitch in
  0..=90 and the two optional buttons. It sets the region (refits the camera), centres on a coordinate, fits a list
  of coordinates, and answers pinch, drag, rotate and tilt gestures. A gesture whose switch is off returns `false`
  and changes nothing. The camera and tracking code that was already in the file is unchanged.
- **Native object export to scripts** (`springboard/sdk/src/script_export.rs`, new). `ExportRegistry` exports
  classes with methods (fixed arity), read-only properties and read-write properties. Calls follow the script
  convention: arguments are cut to the arity and padded with `undefined`. Values use the existing `ScriptValue`
  type from `script_value.rs`. Names are checked as ASCII identifiers, and duplicate classes and members are refused.
- **Accessory interaction paths and subscriptions** (`springboard/core/src/matter_interaction.rs`, new).
  `AttributePath` (endpoint, cluster and attribute, each optionally a wildcard), `CommandPath`, `ReadRequest`,
  `WriteRequest` (concrete path only), `CommandRequest` (unique field IDs), `SubscribeParams` (min not above max)
  and `SubscriptionSet` (subscribe, replace, unsubscribe and the list of subscriptions interested in an attribute).
  It sends nothing: there is no transport, session or wire encoding.

## Official API names mirrored

- JavaScriptCore: `JSExport` (native object export; the members a class publishes to script).
  Doc: https://developer.apple.com/documentation/javascriptcore/jsexport
- MapKit: `MKMapView` (`region`, `setRegion(_:animated:)`, `centerCoordinate`, `setCenter(_:animated:)`,
  `showAnnotations(_:animated:)`, `visibleMapRect`, `isZoomEnabled`, `isScrollEnabled`, `isPitchEnabled`,
  `isRotateEnabled`, `mapType`, `pitchButtonVisibility`, `showsUserTrackingButton`; configurations
  `MKStandardMapConfiguration`, `MKHybridMapConfiguration`, `MKImageryMapConfiguration`).
  Doc: https://developer.apple.com/documentation/mapkit/mkmapview
- Matter: `MTRDevice` (`readAttribute(withEndpointID:clusterID:attributeID:params:)`, `writeAttribute`,
  `invokeCommand`, `readAttributePaths(_:)` with wildcards, `add(_:queue:interestedPathsForAttributes:...)`),
  `MTRAttributePath`, `MTRCommandPath`, `MTRReadParams` (`fabricFiltered`, `shouldFilterByFabric`),
  `MTRSubscribeParams` (`init(minInterval:maxInterval:)`).
  Docs: https://developer.apple.com/documentation/matter/mtrdevice ,
  https://developer.apple.com/documentation/matter/mtrattributepath ,
  https://developer.apple.com/documentation/matter/mtrcommandpath ,
  https://developer.apple.com/documentation/matter/mtrsubscribeparams ,
  https://developer.apple.com/documentation/matter/mtrreadparams

Rules that are this module's own, not the reference's: the zoom and pitch limits and the default switches
(the reference does not state its defaults), the rule that a subscription's minimum interval is not above its
maximum, the rule that a command may not repeat a field, and the rule that an empty read is refused.

## Rows skipped

| Framework slug | Feature | Reason |
|---|---|---|
| extensionfoundation | Adding support for app extensions to your app | Umbrella row. Its four child rows are already `partial` (springboard/sdk/src/peer_session.rs, springboard/ui/src/extension.rs, springboard/core/src/extension_process.rs). This batch adds nothing that would close it honestly. |
| file-provider | Replicated File Provider extension (sync local copies with remote storage) | Needs a remote sync service and a provider process. Cloud sync lives in another repository, and no network service may be added. |
| javascriptcore | C API (engine interface, data types, constants) | A C-level engine interface. The SDK is Rust, and no unsafe code is allowed in this batch. |
| mailkit | Hand text and files to a mail compose window | There is no mail app or compose window to hand to. Adding a share target needs a mail client first. |
| mapkit | Map snapshots (static images) | Needs a map tile source and a map layer in the renderer. No tile data exists in the repository. |
| matter | Controller initialization (fabric, certificates, storage) | Needs key generation, certificate issuance and secure storage. No crypto crate may be added, and std has no such primitives. |
| matter | Clusters (typed On/Off, Level Control, Switch and others) | Cluster and attribute IDs are defined by the Matter specification, which is not among the official Apple pages used for this batch, so they cannot be cited here. |

Note: the `matter` row about clusters and the `matter` controller row stay `gap`; the accessory control row closes
only the path and subscription model, not a working controller.

## Tests

- `springboard/ui/src/mapview.rs` tests: default map view state, disabled gestures change nothing, a drag of half
  the world at zoom 0 crosses the antimeridian (longitude -180), rotation wraps to 330 and tilt is clamped, pinch
  stops at the zoom limit, and `set_region` centres the view.
- `springboard/sdk/src/script_export.rs` tests: identifier rule, method arity padding and truncation, read-write
  property with a refusing setter, read-only property refuses writes, name and duplicate refusal, missing class and
  member errors, handler errors, and sorted member names.
- `springboard/core/src/matter_interaction.rs` tests: wildcard matching, path containment, read and write
  refusals, repeated command fields, interval order, and subscription interest with replace and unsubscribe.

Not run: the batch rule forbids builds. The lead builds once at the end, and the tests above are untested until then.
