# Parity wave 6, batch b07

Closes the two gap rows in this batch that can be built in pure Rust without hardware, a network service or a
recognizer model. Pure models only: no window, no renderer hook, no app wiring yet. Not tested on the VM or on Midget.

## What was built

- **Surface plots for 3D charts** (`springboard/ui/src/chart_surface.rs`, new module, `pub mod` line in
  `springboard/ui/src/lib.rs`). `sample` evaluates a function of x and y on a grid of heights. `project` applies a
  pose (yaw about the vertical axis, then pitch toward the viewer), fits the surface into a frame with one uniform
  scale, and returns one quad per grid cell with its mean depth and a facing value (1.0 square to the viewer, 0.0
  edge-on). Quads come back sorted farthest first for painter's-order drawing. The projection is orthographic only.
- **Inline tip view and style** (`springboard/ui/src/tips.rs`, extended in the existing tipkit model). Adds
  `TipViewStyle` (`Standard` and `Mini`, default `Mini`), `TipSection` (title, message, actions) and `TipView`.
  `TipView::sections` asks the existing `Datastore::is_eligible` and returns no sections when the tip may not show.
  The `Mini` style leaves out the actions (our rule, not checked against a rendered reference). The arrow edge and the
  anchor stay with the popover code in `springboard/sdk/src/widgets.rs`.

## Official API names mirrored

- Swift Charts: `Chart3D` (https://developer.apple.com/documentation/charts/chart3d), `SurfacePlot`
  (https://developer.apple.com/documentation/charts/surfaceplot), `Chart3DPose`, `Chart3DCameraProjection`
  (orthographic only here). Mirrored behaviour: the surface is the function `y = f(x, z)` sampled on a grid; the pose
  is interactive state; the chart is drawn with the depth of each cell.
- TipKit: `TipView` (https://developer.apple.com/documentation/tipkit/tipview), `TipViewStyle` and
  `TipViewStyle.miniTip` (https://developer.apple.com/documentation/tipkit/tipviewstyle/minitip). Mirrored behaviour:
  a tip view shows a tip only when its rules and display frequency allow it.

Official pages were read with `python3 -I tools/parity/docc.py`. The TipView page states that its content is a type
conforming to `Tip` with an optional arrow edge and an action handler. The Chart3D page states that a surface plot
is used to visualize a 3D surface for a function and that the pose is a binding.

## Rows skipped

| Framework slug | Feature | Reason |
|---|---|---|
| speech | Speech recognition on live or recorded audio (framework overview) | Needs a recognizer model and a time-coded audio stream from the audio service. Neither exists, and a model cannot be built honestly in pure Rust here. |
| speech | System dictation entry point | Depends on the recognizer above. The keyboard Mic key draws a glyph and does nothing on tap; wiring it needs the recognizer. |
| speech | Legacy Objective-C recognizer API | A binding for a legacy interface. Not in scope for a Rust desktop, and it depends on the recognizer above. |
| storekit | Promoted purchases | Needs a store-side promotion model and a product catalogue service. |
| storekit | App Store interactions | Needs an account-level store service (subscriptions, transaction sync), which is a network service. |
| translation | System translation popover | Needs an on-device translation model for language pairs. No model is available in pure Rust. |
| user-notifications | Remote notifications and APNs registration | Needs a push service and a device token from a network service. |
| user-notifications | Web push notifications | Needs a push service and push support in the browser engine. |

## Verification

No build was run in this round (lead builds once). The new tests cover: sampling end to end, rejection of bad grids and
non-finite heights, a flat surface facing the viewer (facing 1.0, corners on the 0 to 100 frame), a quarter-turn tip
giving facing 0, the cell count and back-to-front order, a non-positive frame giving nothing, and the tip view
sections for Standard, Mini (default), empty message, event rule and display frequency.
`python3 tools/check-names.py` reports no hits.
